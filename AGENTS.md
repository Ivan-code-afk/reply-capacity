# Reply Capacity — инструкции Codex

## Цель продукта
Одна функция: при заданном ежедневном притоке сообщений, стартовой очереди, минутах на один ответ и ежедневном бюджете времени вычислять очередь за 7 дней и дополнительное время, необходимое для ее ликвидации.

## Ограничения
- Сохранять статическое приложение: HTML/CSS/vanilla JavaScript. Не добавлять backend, API, AI, авторизацию, платежи, базу данных, фреймворки и внешние зависимости без явного запроса владельца.
- Не выдавать сценарный расчет при постоянном потоке за предсказание реального количества сообщений.
- Использовать простые детерминированные механизмы: накопление, арифметика, лимиты, переключение, сравнение. Не заявлять использования исходного кода ДИН-Прогноз.
- Не отправлять введенные данные на сервер. Текущий localStorage допустим.
- Сохранять доступность интерфейса на мобильных устройствах и русский язык.

## Проверка
- После изменения расчетов запускать `node test-core.js`.
- Проверять: 0 новых сообщений, 0 рабочего времени, невозможность одного ответа, пустую очередь, полную разгрузку, целочисленную вместимость, суточный/недельный баланс.
- Для проверки UI запустить локальный HTTP-сервер: `python -m http.server 8000`, открыть `http://localhost:8000/`, проверить на телефонном и настольном размере, ошибки консоли и отсутствие сетевых запросов.
- Все исправления вносить отдельной веткой/PR с кратким описанием, до слияния показывать владельцу.
